# Traducao-Nintendo-Talisman-Digital-Edition-para-Switch
Arquivos para tradução do jogo para Nintendo Switch desbloqueado totalmente revisado. Foi criado com auxilio de I.A, porém testado e todo revisado por mim.
Basta extrair o arquivo e copiar a pasta atmosphere para dentro do cartão SD do seu console
obs: fo utilizado auxílio de i.a, para alteração das fontes, e algum ajustes de blocos de texto já que os que tinha feito, estavam dando alguns bugs nas descrições das cartas
A tradução é gratuita, aproveite ! foi necessário investimento em i.a paga e caso queira fazer uma doação para mais projetos o pix é jandirlima19@gmail.com.
